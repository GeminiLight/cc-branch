User value

Stop rebuilding the same agent environment.

Restore Come back to the same setup

No more reopening agents, terminals, editors, and SSH links by hand. Restore the project environment together.

Agents Keep Agent CLIs organized

Codex, Claude Code, Gemini CLI, Cursor CLI, Kimi, and custom agents stay in one project workspace.

Remote Use local and SSH as one environment

Local folders, SSH projects, GPU boxes, test machines, and tmux sessions can belong to the same workflow.

Daily flow

Start, resume, connect, inspect.

Use the CLI, Web UI, or Desktop to restore the environment, attach to existing sessions, open tools, and check what is broken.

.cc-branch/config.yaml 
workspace: orbit
openWith: cursor
tabs:
  - name: agents
    layoutBackend: tmux
    panes:
      - agent: codex
        resume: planner
      - agent: claude
        label: review
  - name: remote-lab
    ssh:
      host: gpu-dev
      cwd: /srv/orbit
    panes:
      - command: npm run qa
01 define

Save the agents, commands, tools, folders, and SSH targets a project needs.

02 preview

See which agents, commands, tools, and machines will be used before launch.

03 restore

Bring back the project environment with `cc-branch start`.

04 inspect

Catch missing Agent CLIs, bad paths, failed SSH links, and stale state.

Remote workspaces

Local project. Remote machine. Same workspace.

Add projects and panes that live on SSH hosts, then launch them beside local agents and servers. The directory can be local or remote; the workspace still opens as one unit.

local ~/code/orbit cursor
ssh gpu-dev:/srv/orbit tmux

Desktop shell

A quiet desktop shell for local work.

The desktop app wraps the Web UI with a local sidecar, so switching projects, checking status, and restoring sessions feels like a native utility.

Install

Start from the terminal.

Install from source while public registries and signed desktop releases are finalized.

terminal 
pip install git+https://github.com/GeminiLight/cc-branch.git
cc-branch plan
cc-branch start
cc-branch doctor
