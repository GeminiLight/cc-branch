The local control problem

Your project is no longer one terminal.

Modern AI development means agents, shells, dev servers, editor windows, long-lived sessions, and remote boxes all orbiting the same repo. CC Branch gives that orbit a file format and a runtime.

The committed config describes what should exist. The local state remembers what is already running. The CLI and Web UI make the workspace inspectable instead of mysterious.

01

Config that survives the week

Put tabs, panes, agents, commands, directories, environment variables, and openers in `.cc-branch/config.yaml`.

02

Sessions that come back

Start, attach, stop, restart, inspect, prune, and render resume commands for long-running agent sessions.

03

Local truth, team shape

Commit the workspace shape. Keep machine-specific session state out of git. Exactly where it belongs.

04

Doctor before drama

Check tmux, paths, commands, agent references, state drift, and low-risk fixes before a broken workspace wastes the morning.

Workspace anatomy

One config. Multiple execution surfaces.

Use tmux when you want durable background sessions. Use direct mode when the right answer is simply opening a local app or running a normal command. Add SSH when a pane belongs on a server.

Install today

Use the GitHub source package while registries are being prepared.

PyPI, npm, Homebrew, and signed desktop releases are wired in the repo, but public registry publishing is intentionally gated. The source install works now and builds the bundled Web UI.

terminal 
pip install git+https://github.com/GeminiLight/cc-branch.git
cc-branch --help
cc-branch serve
Requires Python 3.10+ Node/npm builds the Web UI from source tmux is needed only for tmux-backed tabs
