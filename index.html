Work scenario

Pick a project. Start working.

CC Branch shows what will open, then restores the terminals, agents, editor, and remote sessions for that project.

Project recipe 
workspace: orbit
openWith: cursor
tabs:
  - name: agents
    layoutBackend: tmux
    panes:
      - agent: codex
        resume: planner
      - agent: claude
        label: review
  - name: remote-lab
    ssh:
      host: gpu-dev
      cwd: /srv/orbit
    panes:
      - command: npm run qa
